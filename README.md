# Spring Boot Web Services Project

REST API developed during my studies of Java, Spring Boot and JPA/Hibernate.

## Technologies

* Java
* Spring Boot
* Spring Data JPA
* Hibernate
* H2 Database
* PostgreSQL
* Maven

## Features

* User management
* Order management
* Product and Category management
* Order items
* Payment processing
* CRUD operations
* Exception handling
* RESTful endpoints

## Concepts Practiced

* REST APIs
* Dependency Injection
* Service Layer Pattern
* Repository Pattern
* Object Relational Mapping (ORM)
* Entity Relationships
* One-to-One
* One-to-Many
* Many-to-One
* Many-to-Many
* Composite Primary Keys
* Exception Handling
* Environment Profiles

## Database Relationships

The project includes several relationship mappings:

* User ↔ Orders
* Order ↔ Payment
* Product ↔ Category
* Order ↔ OrderItem
* Product ↔ OrderItem

## Databases

Development and testing were performed using:

* H2 Database
* PostgreSQL

## Learning Objectives

This project was developed to strengthen backend development skills using Java and Spring Boot, focusing on REST APIs, database persistence, entity relationships and software architecture fundamentals.
